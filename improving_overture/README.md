## improving_overture: steps to clean small buildings, overlaps, and false positives from the integrated Overture/3D-GloBFP

### Notebook 1: GEE Extraction of raster products to building footprints (step1_get_gee_data.ipynb)

Cell 1 extracts Earth Engine raster information for each building footprint and joins the results back to the original building GeoPackage. The workflow takes a city which is matched to the integrated Overture/3D-GloBFP footprints for that city. The outputs are written to a csv: {city}_buildings_alpha_dynamic_25d.csv and geopackage: {city}_overture_buildings_gee.gpkg. It assigns or uses new_id as the join field, removes empty geometries, fixes invalid geometries, and reprojects the processing copy to EPSG:4326. Dynamic World and AlphaEarth are extracted for YEAR = 2025 at SCALE = 10 m, while Google Open Buildings 2.5D is extracted for GOOGLE_25D_YEAR = 2023 at GOOGLE_25D_SCALE = 4 m. To avoid GEE errors, buildings are processed in batches of BATCH_SIZE = 5000, with a PAUSE_SECONDS = 0.5 delay between requests. Dynamic World and AlphaEarth use mean values within each footprint, while Google 2.5D uses the maximum building_presence confidence within each footprint. The cell then calculates the top Dynamic World class, top class probability, built probability, renames the 64 AlphaEarth bands with an alphaearth_ prefix, removes duplicate new_id records, and exports a CSV and GeoPackage containing the original buildings plus GEE-derived attributes.

Cell 2 uses the GEE-enriched GeoPackage to identify AlphaEarth spectral outliers and create t-SNE coordinates for visualization. It reads {city}_overture_buildings_gee.gpkg, expects EXPECTED_ALPHA_BANDS = 64, and keeps only buildings with complete AlphaEarth embeddings for the outlier analysis. The 64 AlphaEarth variables are converted to numeric values and standardized before running an Isolation Forest model. The model parameters are IF_CONTAMINATION = 0.05, IF_N_ESTIMATORS = 300, RANDOM_STATE = 42, and n_jobs = -1. The Isolation Forest labels anomalies as outliers, calculates an anomaly score, and normalizes that score from 0 to 1. The same standardized AlphaEarth feature matrix is then reduced to two dimensions using t-SNE with TSNE_PERPLEXITY = 30, learning_rate = "auto", init = "pca", and RANDOM_STATE = 42. The resulting fields, including isolation_forest_outlier, anomaly scores, and TSNE1/TSNE2, are joined back to the full original GeoPackage by new_id, preserving buildings that lacked complete embeddings but marking them without model results.

Cell 3 creates diagnostic plots from the Isolation Forest and t-SNE output CSV. It reads {city}_buildings_isolation_forest_tsne.csv from the outlier_results_isolation_forest folder and requires the fields TSNE1, TSNE2, dw_top_class_name, isolation_forest_outlier, and google25d_max_confidence. The cell converts t-SNE coordinates and Google 2.5D confidence to numeric values, drops records without valid t-SNE coordinates, and summarizes the number and percentage of Isolation Forest outliers. Google 2.5D confidence is grouped into low confidence < 0.1, medium confidence < 0.5, high confidence ≥ 0.5, and no data. It then exports three 300 dpi figures: t-SNE colored by Dynamic World class, t-SNE colored by Isolation Forest outlier status, and t-SNE colored by Google 2.5D confidence class.

### Notebook 2: Cleaning and dropping false positives (step2_drop_false_and_clean.ipynb)

Cell 1 screens the integrated building layer for conservative false positives and splits the retained features into Overture and 3D-GloBFP layers. The workflow is configured for a city, reading {city}_overture_buildings_gee.gpkg and writing outputs to an ArcGIS project geodatabase. The false-positive screen uses year, isolation_forest_outlier, Dynamic World class and probability (top_class_name and top_probability), google25d_max_confidence, geometry_confidence, and geometry_provider. Recent Overture features are protected with RECENT_YEAR = 2023, and buildings with strong built evidence are retained when Dynamic World class is built and probability is ≥ 0.60. A raster-based false positive is removed only when it is an AlphaEarth outlier, Dynamic World is non-built or built with probability < 0.60, and geometry confidence is not high, or Google 2.5D confidence is ≤ 0.10 and the year is older than 2024. The retained layer is then split by geometry_provider = "3D-GloBFP" into separate 3D-GloBFP and Overture layers for the next cleaning step.

Cell 2 removes remaining duplicate or overlapping Overture footprints where 3D-GloBFP is preferred. It copies the screened Overture and GloBFP layers, assigns temporary IDs named OV_ID and GLO_ID, calculates original polygon areas, and creates an intersection layer between the two sources. For each intersecting pair, the cell computes intersection-over-union using the original Overture area, original GloBFP area, and intersection area. Overture features are marked for removal when IoU > 0.10 using IOU_THRESHOLD = 0.10. Overture features are also removed when they are completely contained within a GloBFP footprint, using an area tolerance of 0.000001. The cell deletes only Overture features; GloBFP features are retained.

Cell 3 merges the cleaned Overture and GloBFP layers back into a single final building layer and removes very small geometries. The inputs are buildings_cleaned_method2_glo_25d and buildings_cleaned_method2_ov_25d, and the merged output is written to E:\buildings\buildings_six_cities_9_13.gpkg as layer buildings_six_cities_9_13. After merging, the cell checks for the required area field area_m2 and removes polygons with area_m2 < 16, using MIN_AREA_M2 = 16. It then reports the original source counts, number of small geometries removed, expected final total, and actual output count as a consistency check.
